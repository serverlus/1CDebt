# Умная Дебиторка — Расширение 1С

Расширение конфигурации 1C:Enterprise для **скоринговой оценки контрагентов** по состоянию дебиторской задолженности.

## Что делает

- Рассчитывает **балл риска (0–100)** для каждого покупателя с активной дебиторкой
- Присваивает **категорию A/B/C/D** (цветовая индикация в таблице)
- Формирует **расшифровку** по 4 факторам с весами
- Позволяет **выгрузить в Excel** с цветовым оформлением

## Алгоритм скоринга

| Фактор | Вес | Штраф |
|--------|-----|-------|
| Макс. дней просрочки | 30% | −3…−30 |
| Доля просроченного долга | 35% | −3…−35 |
| История платежей (12 мес) | 25% | −3…−25 |
| Кол-во просроченных документов | 10% | −3…−10 |

### Категории

| Балл | Категория | Цвет | Смысл |
|------|-----------|------|-------|
| 80–100 | A | Зелёный | Надёжный контрагент |
| 60–79  | B | Жёлтый  | Умеренный риск |
| 40–59  | C | Оранжевый | Высокий риск |
| 0–39   | D | Красный | Критичный — приоритет взыскания |

## Сборка расширения (.cfe)

### Способ 1 — 1C:Конфигуратор (самый простой)

1. Откройте любую базу в режиме **Конфигуратор**
2. Меню **Конфигурация → Расширения конфигурации**
3. Нажмите **Создать** → имя `УмнаяДебиторка`
4. В расширении: **Конфигурация → Загрузить конфигурацию из файлов** → папка `src/cf/`
5. **Конфигурация → Сохранить конфигурацию в файл** → `УмнаяДебиторка.cfe`

### Способ 2 — 1C:EDT

```
File → Import → 1C Extension project → src/cf/
Project → Build → Export .cfe
```

### Способ 3 — ring.exe (CI/CD)

```bat
ring.exe designer /DisableStartupDialogs /N admin /P "" ^
  /LoadConfigFromFiles src\cf ^
  /Extension УмнаяДебиторка ^
  /SaveCfg УмнаяДебиторка.cfe
```

## Установка в рабочую базу

1. Откройте рабочую базу (УТ 11, КА 2, Бухгалтерия 3.x) → **Конфигуратор**
2. **Конфигурация → Расширения конфигурации → Добавить**
3. Выберите файл `УмнаяДебиторка.cfe`
4. Запустите предприятие → **Все функции → Обработки → Умная Дебиторка**

## Адаптация под вашу конфигурацию

В файле `CommonModules/СкорингКонтрагентов/Ext/Module.bsl` замените:

| Место | УТ 11 / КА 2 | Бухгалтерия 3 |
|-------|-------------|----------------|
| Имя регистра | `ВзаиморасчетыСКонтрагентами` | `РасчетыСКонтрагентами` |
| Поле отсрочки | `СрокОплатыПоДоговору` | `СрокПлатежа` |
